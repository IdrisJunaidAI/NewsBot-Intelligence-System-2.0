# Authentic BBC Dataset Integration and Evaluation

## Current evidence status

The approved `BBC News Train.csv` has not been supplied to this final project workspace. Accordingly, the publicly hosted Render application trains on the included **60 synthetic demonstration articles**, whose measured scores are **not** evidence of real BBC model performance. The previous midterm's 96.53% held out accuracy and 96.45% macro F1 are historical results from a different model execution and must not be rebranded as final results.

## Step 1. Obtain the approved dataset

Use the exact instructor approved BBC dataset from the earlier midterm, subject to its licensing rules. Place it locally in `data/raw/BBC News Train.csv`. Do not commit data unless distribution is permitted. The repository's `.gitignore` should protect licensed corpora and model artifacts. Never substitute the synthetic CSV for BBC data in a submitted evaluation.

## Step 2. Audit and fingerprint the file

From the `ITAI2373-NewsBot-Final` folder, run:

```bash
python scripts/validate_bbc_csv.py "data/raw/BBC News Train.csv"
```

The utility writes `data/results/bbc_preflight.json` with SHA256, original and retained row counts, category distribution, source coverage, date coverage, and warnings about the five expected BBC classes. This audit does not train a model and does not disclose article text.

Check whether the correct columns (`Text`, `Category`) exist and that category mapping normalizes `tech` to `technology`. Review dropped, duplicate, and missing records before training. The BBC training set is generally undated, so do not infer publication trend charts if the provided copy lacks valid dates.

## Step 3. Run an actual evaluation

```bash
python train.py --csv "data/raw/BBC News Train.csv"
python -m pytest -q
```

This trains a Logistic Regression / TF IDF classifier with an independent stratified 80/20 holdout and performs training partition cross validation against Majority Baseline, Multinomial Naive Bayes, Logistic Regression, and Linear SVM. The training script writes a local model to `data/models/newsbot2.joblib` and numeric metrics to `data/results/training_metrics.json`.

Capture the dataset SHA256, random seed 42, filtered class distribution, held out macro F1, accuracy, class level precision and recall, topic interpretations, and the date of execution. The classifier's probabilities are not guaranteed to be calibrated. Report limitations and class imbalance. Compare with the previous midterm only after confirming comparable class definitions, sample selection, and test methodology.

## Step 4. Verify the dashboard against real data

After local training, start Flask:

```bash
python app.py
```

Open `http://127.0.0.1:5000` and compare `/api/dashboard` to `data/results/training_metrics.json`. Check that `meta.synthetic` is `false`, the category counts sum to the retained article total, each topic assignment distribution sums to the corpus size, and no timeline is invented when publication dates are missing.

## Step 5. Decide how to publish the real model

The current Render Blueprint runs `python train.py --demo` deliberately. Do **not** change this to BBC training until you have confirmed rights to distribute or build from the approved corpus and can deliver it through an authorized deployment mechanism. A model serialized with joblib must only be loaded if it was generated by trusted code and data. Avoid putting raw licensed BBC text into public repos, model files, logs, or API responses without explicit permission.

A separate, rights compliant artifact deployment flow can replace demo training once the data source is available. This change requires a fresh deployment and verification. Keep the demonstration label until deployment of the real model has been confirmed.

## Data and research integrity

An evaluation on training labels alone is not equivalent to performance on independent publications. BBC categories are not a live news feed and the original corpus provides no substantiated 2026 news coverage. Real time capabilities and external semantic search must be tested and documented separately. No academic or business performance claims should be based solely on synthetic teaching examples.
