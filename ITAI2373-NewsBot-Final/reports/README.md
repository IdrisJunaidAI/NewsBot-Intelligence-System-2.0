| --- | --- |

The student reports the professor approves individual completion. These PDF and PowerPoint files were prepared before the newest bonus UI addition. For current bonus implementations use `../docs/BONUS_EVIDENCE.md` and the deployed application; no claim that the older PDFs contain screenshots of the new features is made.
